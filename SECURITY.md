# Security Policy

## Supported Versions

Only the current `master` branch is supported.

## Reporting Security Issues

Open a private vulnerability report on GitHub if available. If not, contact the maintainer directly.

Do not open a public issue for vulnerabilities that expose users to malicious code execution, dependency compromise, or unsafe file handling.

## Data Handling

This app is static and stores no data on a server. History import/export happens locally in the browser through JSON files selected by the user.

Do not add analytics, telemetry, external persistence, or backend services without a clear public discussion and documentation update.
